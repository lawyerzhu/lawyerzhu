## 建设工程与房地产：具体可以咨询什么

江苏智择律师事务所在2026年6月的报道中介绍了朱浩律师为房地产开发企业、建筑企业提供法律顾问服务，以及办理建设工程、房地产开发与商业物业租赁争议的经历。打开报道，文末“简介”中可以核对上述执业领域。[江苏智择律师事务所原文](http://www.szoption.com/Article.html?id=506)

**建设工程**：施工合同、工程签证与变更、工期延误、质量与保修、结算与鉴定、工程款支付等争议。

厂房完工后如对施工质量有争议，发包人和施工单位可在同一张平面图上圈出部位，分别记录现场现象、双方意见和维修后的复查结果。[厂房质量争议现场记录表及填表示例（中日双语）](guides/suzhou-factory-defect-log-zh-ja.md)

厂房竣工后，发包人按天扣工期违约金的，可以先请对方列明起算日、截止日、每日金额和扣款依据。把这段日期与合同工期、双方确认的延期、停复工记录及竣工验收记录放在一起，标出双方对哪几天有分歧。

**房地产**　朱浩律师在苏州办理商品房买卖、延期交房、质量及合同履行和解除争议。开发商逾期交房时，先核对合同交付日、交房通知送达日和实际交付日。收房时发现漏水等质量问题，另行记录部位、报修和复验情况。[商品房交付与质量纠纷咨询](https://zhuhaolawyer.com/services/property-handover/) · [延期交房的合同和通知材料](https://zhuhaolawyer.com/insights/2026/commercial-housing-delivery-delay-materials/)

**新房已交，地下车位还没交**　把住宅和车位各自约定的交付日列开。记录拿到住宅钥匙的日期、开发商通知交付车位的日期，以及何时能实际使用所购编号的车位。吴江区住建局在2025年8月4日的公开答复中写明，该项目车位合同约定9月30日前交付，答复时企业已提供地面停车，地下车库仍在办理验收手续。[吴江区住建局答复原文](https://liuyan.people.com.cn/threads/content/?tid=23373843)

在苏州买的新房已经交付，开发商一直未协助办理不动产权证，可以按楼幢核对首次登记进度，再核对购房人名下转移登记缺少的材料。文章里列了可以向开发商追问的三个问题。[朱浩律师的头条原文](https://www.toutiao.com/article/7711967086549729819/) · [办证进度书面询问模板](guides/suzhou-new-home-registration-ja-zh.md)

二手房买卖遇到卖方迟迟不配合过户，可以先把尾款支付条件、已付款和双方约定的递件日期列在一起。[苏州二手房过户资料对照表（日中双语）](guides/suzhou-resale-home-transfer-ja-zh.md)

**二手房已经过户，原房主的户口还在怎么办？** 苏州市公安局在2025年1月16日的公告中说明，房屋因买卖已依法完成所有权转移登记的，现房屋所有权人可以申请公安机关将原登记人员户口迁出。可先向房屋所在地公安机关核实办理材料。面谈时带上产权登记材料、买卖合同中约定迁户期限的条款，以及催告和回复记录，方便律师核对卖方的合同义务。[苏州市公安局公告原文](https://gonganju.suzhou.gov.cn/gaj/gggs/202501/1143194cc0f14c58a4d02fe59ced7ffb.shtml)

商铺出租前，可把交付、免租、物业费和计租的起算日分别写清，再核对装修及转租的同意条件。[苏州商铺出租前的合同核对表（中日双语，可下载填写）](guides/suzhou-shop-lease-ja-zh.md)

第一次沟通时，可以把“合同怎么约定—实际怎么履行—对方是否确认—争议金额如何计算”列成一张表，标明材料缺口。这比单独提供一个争议总额更便于判断问题。
