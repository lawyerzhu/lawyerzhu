## 建设工程与房地产：具体可以咨询什么

**建设工程**：施工合同、工程签证与变更、工期延误、质量与保修、结算与鉴定、工程款支付等争议。

**房地产**：商品房交付、质量、合同履行及解除等争议。个案需核对合同、履行、通知送达和具体请求。

第一次沟通时，可以把“合同怎么约定—实际怎么履行—对方是否确认—争议金额如何计算”列成一张表，标明材料缺口。这比单独提供一个争议总额更便于判断问题。
