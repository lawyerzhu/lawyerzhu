# 苏州商铺出租前的合同核对表｜蘇州で店舗を貸す前の契約チェックシート

[下载中日双语空表（CSV）／日中対訳の記入用シートをダウンロード](https://raw.githubusercontent.com/lawyerzhu/lawyerzhu/main/guides/suzhou-shop-lease-ja-zh.csv)

把租约草稿、平面图和交付清单放在手边。在空表中填上合同条款页码、双方已经同意的内容，以及还要对方确认的问题。可以在自己的 Excel 或 WPS 里填写，带到面谈现场。

賃貸借契約の草案、物件の平面図、引渡明細を用意し、契約書の該当ページ、合意済みの内容、相手方に確認する点を記入してください。記入したシートを手元に保存して相談時に持参できます。

### 租金和物业费，分别从哪一天算｜賃料と管理費の起算日

**填写示例**　草稿约定5月1日交钥匙，5月1日至31日免租，6月1日起计租，但费用条款只写“物业费由承租人承担”。在“已约定”栏写“6月1日起计租”，在“待确认”栏写“5月物业费由谁承担，从哪一天起算”。如果物业公司另有收费约定，把相应文件一并带来。

**記入例**　5月1日に鍵を渡し、5月分の賃料は免除、6月1日から賃料が発生する契約案を想定します。「管理費は借主負担」としか書かれていなければ、合意済み欄には「賃料は6月1日から」、確認欄には「5月分の管理費は誰がいつから負担するか」と記入します。

### 面谈时逐项核对｜面談で確認する項目

| 项目／項目 | 带什么、核对什么／資料と確認事項 |
|---|---|
| 房屋及用途／物件と用途 | 对照门牌、平面图上的铺位和约定经营用途。／所在地・図面上の区画と契約上の用途を照合します。 |
| 租期及费用／契約期間と費用 | 分别写下交付、计租和费用起算日，标出递增租金的基数。／引渡日、賃料と諸費用の起算日、賃料増額の基準額を分けて記入します。 |
| 装修和维修／内装と修繕 | 保留进场照片，在图纸上圈出拟改造部位，写明谁批准、谁维修、退场时哪些设施要拆。／引渡時の写真と図面に工事箇所を示し、承認者・修繕の分担・退去時に撤去する設備を確認します。 |
| 转租／転貸 | 找出合同里的同意条件，记录同意对象、范围和留存方式。／契約書の承諾に関する条項を確認し、転貸先、対象範囲、承諾の記録方法を整理します。 |
| 押金与退场／保証金と明渡し | 对照押金收据、退场验收清单、返还时点和扣款凭据。／保証金の受領書、明渡し時の確認表、返還時期と控除の根拠資料を照合します。 |

《中华人民共和国民法典》第704条列出租赁合同通常约定的事项。装修涉及改善租赁物或增设他物时，可核对第715条。拟将商铺转租给第三人的，可核对第716条。中国民法典の第704条は賃貸借契約の主な記載事項、第715条は賃借物の改良・設備等の追加、第716条は第三者への転貸を扱います。[最高人民法院公布的《中华人民共和国民法典》全文（中文）](https://www.court.gov.cn/zixun/xiangqing/233181.html)
